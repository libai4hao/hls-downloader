# 功能清单

`hls-downloader` 的功能清单。状态分三类：✅ 已实现 / 🚧 规划中 / ⏸ 暂不做。

---

## 下载核心

| 功能 | 说明 | 状态 |
|------|------|------|
| 网页链接下载 | 粘贴网页链接，yt-dlp 自动解析出视频流（标题最准） | ✅ |
| 视频直链下载 | 直接喂 m3u8 / mp4 / ts 直链 | ✅ |
| 设置下载文件名 | `-o/--output <文件名>` 固定输出文件名（自动补 `.mp4`） | ✅ |
| 同名文件处理 | 默认加序号 `名称 (1).mp4`，`--overwrite` 强制覆盖 | ✅ |
| 批量下载 | `--batch <文件>` 逐行 `URL [文件名]` 批量下载，单条失败不中断 | ✅ |
| 加密 HLS（AES-128） | m3u8 带 `#EXT-X-KEY:METHOD=AES-128` 时自动解密分片 | ✅ |
| 合并转封装 MP4 | 分片下载后由 ffmpeg 转封装为 mp4 | ✅ |
| 断点续传 | yt-dlp 自带 `retries=10` / `fragment_retries=10`，失败自动重试、可重跑续传 | ✅ |
| 变体（master）m3u8 | 主 m3u8 只有多分辨率子流时，yt-dlp 自动选流 | ✅ |
| 播放列表下载 | 单视频下载（`noplaylist=True`），不展开播放列表 | ✅（当前固定单视频） |
| DRM（Widevine/PlayReady） | `SAMPLE-AES` 等 DRM 流 | ⏸（yt-dlp 无解，超出范围） |

## 反爬 / 防盗链 / 登录态

| 功能 | 说明 | 状态 |
|------|------|------|
| 读 cookies 文件 | `--cookies <文件>`，支持 Netscape cookies.txt 与 Cookie-Editor JSON（自动识别） | ✅ |
| 从浏览器读 cookie | `-b/--browser`（仅 firefox 等非 Chromium 可靠；chrome/edge 受 ABE 限制） | ✅（受限） |
| cookies.txt 导出指南 | `doc/cookies导出指南.md`，扩展导出 + UA/IP 绑定说明 | ✅ |
| 覆盖 User-Agent | `--ua/--user-agent <串>` | ✅ |
| 带 Referer | `-r/--referer <url>` | ✅ |
| 走代理 | `--proxy <url>` | ✅ |
| TLS 指纹伪装（impersonate） | curl_cffi 模拟浏览器指纹 | ⏸（对 Cloudflare Turnstile 无效，已评估不引入） |

## 配置

| 功能 | 说明 | 状态 |
|------|------|------|
| config.json 读取 | 脚本同目录 `config.json`，命令行 > config > 默认值 | ✅ |
| 配置示例 | `config.example.json` | ✅ |
| 输出目录配置 | `out_dir`，位置参数 / config 均可指定 | ✅ |

## 下载历史记录

| 功能 | 说明 | 状态 |
|------|------|------|
| 自动记录 | 每次下载（成功/失败）追加一行到 `download_history.log`（可读 txt/log 格式） | ✅ |
| 可配置开关 | config 里 `history: false` 关闭，或命令行 `--no-history` 单次关闭 | ✅ |
| 自定义历史文件 | config 里 `history_file`，或命令行 `--history-file` | ✅ |
| 历史查询/去重/清理 | 按 URL 查询、去重跳过、清理过期记录 | 🚧 |
