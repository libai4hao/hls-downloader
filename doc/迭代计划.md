# 迭代计划

`hls-downloader` 的版本路线与优先级。优先级：P0 必须 > P1 应该 > P2 可选。

---

## V1.0 —— 核心下载（已完成）

- [x] yt-dlp + ffmpeg 封装，支持网页链接 / m3u8 直链
- [x] 加密 HLS（AES-128）自动解密 + 合并 MP4
- [x] 输出目录位置参数 + 默认 `downloads/`
- [x] 自动定位 yt-dlp / ffmpeg

## V1.1 —— 反爬 / 防盗链 / 登录态（已完成）

- [x] `--cookies` / `-b/--browser` 登录态（二选一）
- [x] `--ua/--user-agent` 覆盖 User-Agent
- [x] `-r/--referer` 防盗链 Referer
- [x] `--proxy` 代理
- [x] 参数对照文档、config 示例
- [x] 解决 `jav.sb` 类 Cloudflare Turnstile 站点的 `403`/`WinError 10054`（用浏览器登录态）

## V1.2 —— 配置与下载历史（本次，已完成）

- [x] `config.json` 读取（命令行 > config > 默认值）
- [x] 下载历史记录 `download_history.log`（默认开启，txt/log 可读格式）
- [x] 历史开关：config `history` / 命令行 `--no-history`
- [x] 自定义历史文件：config `history_file` / 命令行 `--history-file`
- [x] 功能清单、迭代计划文档

## V1.3 —— 登录态落地（本次，已完成）

- [x] `doc/cookies导出指南.md`：浏览器扩展导出 cookies.txt 的图文指引 + `cf_clearance` 绑定 UA+IP 说明
- [x] 各文档标注 `-b chrome` / `-b edge` 受 App-Bound Encryption（ABE）限制不可用（yt-dlp 官方无解）
- [x] 无登录平台回归测试：公开 HLS 流 `test-streams.mux.dev` 下载成功（478.94 MiB）
- [x] `--cookies` 自动识别 Cookie-Editor 的 JSON 导出并转 Netscape（登录态落地，FC2 登录墙复测通过、标题恢复）
- [x] 修下载历史把 ANSI 颜色码写进日志的小瑕疵

## V1.4 —— 文件名 / 去重 / 批量下载（本次，已完成）

- [x] `-o/--output <文件名>` 固定输出文件名（不含扩展名自动补 `.mp4`，已含扩展名则原样）
- [x] 同名文件去重：默认加序号 `名称 (1).mp4`，`--overwrite` 强制覆盖
- [x] `--batch <文件>` 批量下载：每行 `URL [文件名]`，`#` 注释与空行忽略，单条失败不中断

## V1.5 —— 下载失败重试队列（本次，已完成）

- [x] `--retries <次数>` 下载失败额外重试次数，默认 3（0 关闭重试）
- [x] 批量队列式重试：第一轮全跑，失败条目进队列统一重试
- [x] 重试耗尽仍失败的条目写 `failed_downloads.txt`（每行 `URL [文件名]`，可回喂 `--batch`）
- [x] 单条模式失败后额外重试 N 次，仍失败才报错

## V2.0 —— 计划中（按优先级）

|--------|----------|----------------------------------|

## 暂不做

- TLS 指纹伪装（curl_cffi impersonate）——对 Cloudflare Turnstile 无效，已评估不引入。
- DRM（Widevine/PlayReady）——超出 yt-dlp 能力范围。
- GUI —— 保持命令行工具，轻量。
