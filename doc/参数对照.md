# 参数对照

`hls_download.py` 的命令行参数 ↔ yt-dlp 底层选项映射，附使用场景与示例。

---

## 参数速览

| 命令行参数 | 类型 | 是否必填 | 映射到 yt-dlp | 说明 |
|-----------|------|---------|--------------|------|
| `url` | 位置 | 是 | `extract_info(url=…)` | 网页链接 或 m3u8 直链 |
| `out_dir` | 位置 | 否 | `outtmpl`（拼接目录） | 输出目录，默认脚本同目录 `downloads/` |
| `--cookies <文件>` | 可选 | 否 | `cookiefile` | 读 cookies 文件（Netscape cookies.txt 或 Cookie-Editor 的 JSON 导出，自动识别） |
| `-b, --browser <名>` | 可选 | 否 | `cookiesfrombrowser=(名,)` | 从浏览器读 cookie（仅 firefox 等非 Chromium 可靠） |
| `--ua, --user-agent <串>` | 可选 | 否 | `http_headers["User-Agent"]` | 覆盖 User-Agent |
| `-r, --referer <url>` | 可选 | 否 | `http_headers["Referer"]` | 防盗链 Referer |
| `--proxy <url>` | 可选 | 否 | `proxy` | 代理，如 `http://127.0.0.1:7890` |
| `--no-history` | 可选 | 否 | （脚本内开关） | 本次不写入下载历史记录 |
| `--history-file <文件>` | 可选 | 否 | （脚本内路径） | 下载历史文件路径，默认脚本同目录 `download_history.log` |

> `--cookies` 与 `-b/--browser` 互斥：两者都设置 cookie，同时传会报错。
> `--ua` 与 `-r/--referer` 若同时传，会合并进同一个 `http_headers` 字典。
> 以上所有参数也可通过脚本同目录的 `config.json` 配置（键名同长参数名），优先级：命令行参数 > config.json > 内置默认值。示例见 [config.example.json](../config.example.json)。

## 逐参数详解

### `url`（位置，必填）

要下载的地址。支持两种：

- **网页链接**（推荐，标题最准）：如 `https://www.example.com/video/xxx`
- **视频直链（m3u8）**：如 `https://cdn.example.com/hls/xxx.m3u8&sign=xxx`

```bat
python hls_download.py "https://www.example.com/video/xxx"
```

### `out_dir`（位置，可选）

输出目录。省略时默认落到脚本同目录下的 `downloads/`。

```bat
python hls_download.py "https://www.example.com/video/xxx" "D:\下载"
```

### `--cookies <文件>`

读取 cookies 文件，用于需要登录态或 `cf_clearance` 的站点。支持两种格式，脚本自动识别：

- **Netscape `cookies.txt`**：Get cookies.txt LOCALLY 等扩展导出的标准格式，直接透传。
- **JSON**：Cookie-Editor 等扩展导出的 JSON，脚本会**自动转成 Netscape 临时文件**喂给 yt-dlp（下载结束自动清理），无需手动转换。

> 关键：`cf_clearance` 这类 cookie 绑定「User-Agent + 出口 IP」，所以通常要**同时用 `--ua` 带上与浏览器一致的 UA，且出口 IP 也要一致**（否则被服务器判定不匹配）。

```bat
:: 直接喂 JSON（Cookie-Editor 导出），脚本自动转换
python hls_download.py "https://video.fc2.com/en/content/xxx" --cookies "conf\video.fc2.com.json"

:: 或 Netscape cookies.txt
python hls_download.py "https://jav.sb/jav/xxx.html" --cookies cookies.txt --ua "Mozilla/5.0 ..."
```

### `-b, --browser <名>`

从浏览器自动读取 cookie，不用手动导出。可选 `chrome` / `firefox` / `edge` 等（yt-dlp 支持的所有浏览器名）。

> ⚠️ **重要限制**：新版 Chrome / Edge（开启 App-Bound Encryption 后）的 cookie 库被锁且用 v20 加密，
> yt-dlp **官方无解**（[yt-dlp#15401](https://github.com/yt-dlp/yt-dlp/issues/15401)），`-b chrome` / `-b edge`
> 会报 `Could not copy Chrome cookie database`。因此登录态请**优先用 `--cookies` 导出方案**
> （见 [cookies导出指南.md](cookies导出指南.md)）；`-b` 目前仅对 Firefox 等非 Chromium 浏览器可靠。

```bat
python hls_download.py "https://www.example.com/video/xxx" -b firefox
```

### `--ua, --user-agent <串>`

覆盖默认 User-Agent。某些站点按 UA 判断是否放行。

```bat
python hls_download.py "https://cdn.example.com/hls/xxx.m3u8" --ua "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120.0 Safari/537.36"
```

### `-r, --referer <url>`

防盗链 Referer，站点会校验请求来源。

```bat
python hls_download.py "https://cdn.example.com/hls/xxx.m3u8" -r "https://www.example.com/"
```

### `--proxy <url>`

走代理。本地常见 Clash 类代理端口 7890。

```bat
python hls_download.py "https://www.example.com/video/xxx" --proxy "http://127.0.0.1:7890"
```

### `--no-history` / `--history-file <文件>`

下载历史记录（默认开启）：每次下载成功或失败，都会向 `download_history.log`
追加一行可读文本（txt/log 格式）。每行形如：
`时间 [成功/失败] 标题 (id=xxx) | url | 文件路径或错误信息`。

- `--no-history`：本次下载不写历史。
- `--history-file <文件>`：自定义历史文件路径（默认脚本同目录 `download_history.log`）。

```bat
:: 下载但不记录历史
python hls_download.py "https://www.example.com/video/xxx" --no-history

:: 历史写到指定文件
python hls_download.py "https://www.example.com/video/xxx" --history-file "D:\logs\dl.log"
```

也可在 `config.json` 里全局配置：`"history": false` 关闭、`"history_file": "..."` 指定路径。

## 组合示例

站点需要「登录态 + 防盗链 + 代理」时，可组合使用：

```bat
python hls_download.py "https://cdn.example.com/hls/xxx.m3u8" ^
  --cookies cookies.txt ^
  --ua "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120.0 Safari/537.36" ^
  -r "https://www.example.com/" ^
  --proxy "http://127.0.0.1:7890"
```

> PowerShell 里换行用反引号 `` ` ``，CMD 里用 `^`。URL 含 `&` 时必须加双引号。
