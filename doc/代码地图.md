### 2.3 关键代码位置（按功能）

**ffmpeg 定位**（`_find_ffmpeg_dir`）：
- `../hls_download.py:57-59`：先看环境变量 `FFMPEG_LOCATION`
- `../hls_download.py:60-63`：再 glob 同目录/上级目录 `ffmpeg*/bin/`

**yt-dlp 定位**（`_setup_ytdlp`）：
- `../hls_download.py:69-71`：先 `import yt_dlp` 试系统安装
- `../hls_download.py:72-80`：再 `sys.path.insert(0, lib)` 用本地 `ytdlp_lib/`

**参数解析**（`_parse_args`）：
- `../hls_download.py:234-239`：位置参数 `url`（可选）、`out_dir`（可选）
- `../hls_download.py:242-246`：互斥组 `--cookies` / `-b/--browser`
- `../hls_download.py:249-252`：`--ua/--user-agent`、`-r/--referer`、`--proxy`
- `../hls_download.py:255-260`：`-o/--output`、`--overwrite`、`--batch`
- `../hls_download.py:263-266`：`--no-history`、`--history-file`

**优先级合并**（`main` 前半）：
- `../hls_download.py:353-356`：`cookies`/`browser` 取命令行或 config，同时给则 `sys.exit`
- `../hls_download.py:359-365`：`--cookies` 指向 JSON 时转 Netscape 临时文件
- `../hls_download.py:367-369`：`user_agent`/`referer`/`proxy` 同理
- `../hls_download.py:371-374`：`out_dir`/`history_file` 用 `_resolve_path` 归一化
- `../hls_download.py:376`：`history_enabled = bool(config.get("history", True)) and not args.no_history`
- `../hls_download.py:381-386`：互斥校验（`url` vs `--batch`、`--output` vs `--batch`、二选一必填）

**ydl_opts 构建**（`main` 中段）：
- `../hls_download.py:388-398`：基础 `ydl_opts`（`ffmpeg_location`/`format=best`/`merge_output_format=mp4`/`noplaylist`/`concurrent_fragment_downloads=16`/`retries=10`/`fragment_retries=10`）
- `../hls_download.py:401-404`：按需追加 `cookiefile` / `cookiesfrombrowser`
- `../hls_download.py:407-413`：合并 `http_headers`（`User-Agent` / `Referer`）
- `../hls_download.py:416-417`：按需追加 `proxy`

**下载与历史**（`_download_one` + `main` 末段）：
- `../hls_download.py:287`：`tempfile.mkdtemp(dir=out_dir, prefix=".hls_staging_")` 建 staging
- `../hls_download.py:289-297`：`want_name` 时 outtmpl 用固定文件名，否则默认模板
- `../hls_download.py:301-302`：`with yt_dlp.YoutubeDL(opts) as ydl: info = ydl.extract_info(url=..., download=True)`
- `../hls_download.py:304-318`：从 `requested_downloads` 取 filepath（回退扫 staging）→ `_move_to_final`
- `../hls_download.py:320-323`：回填 `entry` 的 `title`/`id`/`filepath`
- `../hls_download.py:329-332`：异常分支，`entry["status"]="failed"`、记 `error`
- `../hls_download.py:333-336`：`finally` 记历史 + `shutil.rmtree(staging_dir)`
- `../hls_download.py:420-434`：`main` 里批量循环（打印 `[i/N]`、失败继续、汇总）/ 单条 re-raise
- `../hls_download.py:440-445`：`finally` 清理 JSON 转换出的临时 cookie 文件
