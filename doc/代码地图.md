### 2.3 关键代码位置（按功能）

**ffmpeg 定位**（`_find_ffmpeg_dir`）：
- `../hls_download.py:47-49`：先看环境变量 `FFMPEG_LOCATION`
- `../hls_download.py:50-53`：再 glob 同目录/上级目录 `ffmpeg*/bin/`

**yt-dlp 定位**（`_setup_ytdlp`）：
- `../hls_download.py:59-63`：先 `import yt_dlp` 试系统安装
- `../hls_download.py:64-69`：再 `sys.path.insert(0, lib)` 用本地 `ytdlp_lib/`

**参数解析**（`_parse_args`）：
- `../hls_download.py:167-170`：位置参数 `url`（必填）、`out_dir`（可选）
- `../hls_download.py:173-176`：互斥组 `--cookies` / `-b/--browser`
- `../hls_download.py:179-182`：`--ua/--user-agent`、`-r/--referer`、`--proxy`
- `../hls_download.py:185-188`：`--no-history`、`--history-file`

**优先级合并**（`main` 前半）：
- `../hls_download.py:207-210`：`cookies`/`browser` 取命令行或 config，同时给则 `sys.exit`
- `../hls_download.py:212-219`：`--cookies` 指向 JSON 时转 Netscape 临时文件
- `../hls_download.py:221-223`：`user_agent`/`referer`/`proxy` 同理
- `../hls_download.py:225-228`：`out_dir`/`history_file` 用 `_resolve_path` 归一化
- `../hls_download.py:230`：`history_enabled = bool(config.get("history", True)) and not args.no_history`

**ydl_opts 构建**（`main` 中段）：
- `../hls_download.py:237-248`：基础 `ydl_opts`（`ffmpeg_location`/`outtmpl`/`format=best`/`merge_output_format=mp4`/`noplaylist`/`concurrent_fragment_downloads=16`/`retries=10`/`fragment_retries=10`）
- `../hls_download.py:251-254`：按需追加 `cookiefile` / `cookiesfrombrowser`
- `../hls_download.py:257-262`：合并 `http_headers`（`User-Agent` / `Referer`）
- `../hls_download.py:265-266`：按需追加 `proxy`

**下载与历史**（`main` 末段）：
- `../hls_download.py:279-280`：`with yt_dlp.YoutubeDL(ydl_opts) as ydl: info = ydl.extract_info(url=..., download=True)`
- `../hls_download.py:282-289`：从 `info["requested_downloads"][0]` 取 `filepath` 打印
- `../hls_download.py:291-295`：回填 `entry` 的 `title`/`id`/`filepath`
- `../hls_download.py:296-301`：异常分支，`entry["status"]="failed"`、记 `error`、记历史后 `raise`
- `../hls_download.py:302-304`：成功分支，记历史
- `../hls_download.py:305-310`：`finally` 清理 JSON 转换出的临时 cookie 文件
