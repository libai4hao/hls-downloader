# 代码地图

## 1. 文件总览

### 2.3 关键代码位置（按功能）

**ffmpeg 定位**（`_find_ffmpeg_dir`）：
- `../hls_download.py:65-67`：先看环境变量 `FFMPEG_LOCATION`
- `../hls_download.py:68-74`：再 glob `RESOURCE_DIR`/`DATA_DIR`（非 frozen 追加 ROOT）的 `ffmpeg*/bin/`

**yt-dlp 定位**（`_setup_ytdlp`）：
- `../hls_download.py:80-82`：先 `import yt_dlp` 试系统安装
- `../hls_download.py:83-94`：再 `sys.path.insert(0, lib)` 用本地 `ytdlp_lib/`

**参数解析**（`_parse_args`）：
- `../hls_download.py:284-288`：位置参数 `url`（可选）、`out_dir`（可选）
- `../hls_download.py:292-296`：互斥组 `--cookies` / `-b/--browser`
- `../hls_download.py:299-302`：`--ua/--user-agent`、`-r/--referer`、`--proxy`
- `../hls_download.py:305-312`：`-o/--output`、`--overwrite`、`--batch`、`--retries`
- `../hls_download.py:315-318`：`--no-history`、`--history-file`

**优先级合并**（`main` 前半）：
- `../hls_download.py:453-457`：`cookies`/`browser` 取命令行或 config，同时给则 `sys.exit`
- `../hls_download.py:459-466`：`--cookies` 指向 JSON 时转 Netscape 临时文件
- `../hls_download.py:468-470`：`user_agent`/`referer`/`proxy` 同理
- `../hls_download.py:472-475`：`out_dir`/`history_file` 用 `_resolve_path` 归一化（基准 DATA_DIR）
- `../hls_download.py:477`：`history_enabled = bool(config.get("history", True)) and not args.no_history`
- `../hls_download.py:479-487`：`retries` 取命令行或 config（默认 3），非法值/负数 `sys.exit`
- `../hls_download.py:492-497`：互斥校验（`url` vs `--batch`、`--output` vs `--batch`、二选一必填）

**ydl_opts 构建**（`main` 中段）：
- `../hls_download.py:499-509`：基础 `ydl_opts`（`ffmpeg_location`/`format=best`/`merge_output_format=mp4`/`noplaylist`/`concurrent_fragment_downloads=16`/`retries=10`/`fragment_retries=10`）
- `../hls_download.py:511-515`：按需追加 `cookiefile` / `cookiesfrombrowser`
- `../hls_download.py:517-524`：合并 `http_headers`（`User-Agent` / `Referer`）
- `../hls_download.py:526-528`：按需追加 `proxy`

**下载与历史**（`_download_one` + `_run_single`/`_run_batch` + `main` 末段）：
- `../hls_download.py:338`：`tempfile.mkdtemp(dir=out_dir, prefix=".hls_staging_")` 建 staging
- `../hls_download.py:340-348`：`want_name` 时 outtmpl 用固定文件名，否则默认模板
- `../hls_download.py:354-355`：`with yt_dlp.YoutubeDL(opts) as ydl: info = ydl.extract_info(url=..., download=True)`
- `../hls_download.py:357-371`：从 `requested_downloads` 取 filepath（回退扫 staging）→ `_move_to_final`
- `../hls_download.py:373-381`：回填 `entry` 的 `title`/`id`/`filepath` + 打印结果
- `../hls_download.py:382-389`：异常分支 `entry["status"]="failed"` 记 `error`；`finally` 记历史 + `shutil.rmtree(staging_dir)`
- `../hls_download.py:394-405`：`_run_single`（单条：失败额外重试 retries 次，仍失败返回 error）
- `../hls_download.py:408-440`：`_run_batch`（批量：第一轮全跑 → `_retry_pending` 队列重试 → `_write_failed_list` 写失败清单 → 汇总）
- `../hls_download.py:530-541`：`main` 末段调 `_run_batch`/`_run_single`，单条失败 `raise err`
- `../hls_download.py:542-547`：`finally` 清理 JSON 转换出的临时 cookie 文件
